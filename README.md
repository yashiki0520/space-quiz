# Orbit Quiz

Orbit Quiz is a small, responsive space-themed quiz that runs as a static web page. It includes multiple-choice questions, answer feedback, score tracking, and light and dark color schemes.

## Run locally

No build step or dependencies are required. Open `index.html` in a web browser, or serve the repository directory with any static web server.

## Deployment

GitHub Actions publishes `index.html` to GitHub Pages whenever changes are pushed to `main`. The workflow can also be run manually from the Actions tab.
